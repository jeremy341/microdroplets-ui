## Important status language

The application can expose a software control or vendor API capability without
that capability being validated on every physical board or camera. When a page
describes a limitation or a known risk, treat it as operational guidance until
the hardware validation matrix says otherwise.

For developer internals, use the [developer documentation](../developer/INDEX.md).
